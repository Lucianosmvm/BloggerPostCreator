C# é uma linguagem poderosa, moderna e muito usada no desenvolvimento de apps, jogos e sites. Se você está começando agora, esse é o guia perfeito pra você entender a base de tudo!

🔎 1. Tipos de Dados em C#

📌 1.1 Tipos Primitivos (ou de Valor)

int: Números inteiros (ex: idade, quantidade)

int idade = 25;

float: Números com decimais e precisão simples

float altura = 1.75f;
Observação: Não esqueça do f no final dos números float!

double: Decimais com precisão maior

double peso = 70.5;

char: Apenas um único caractere

char inicialDoNome = 'A';

bool: Verdadeiro ou falso

bool isProgramador = true;

string: Sequência de texto

string nome = "João";

📌 1.2 Tipos Referenciais

Armazenam referência para objetos na memória. Um exemplo comum:

int[] numeros = {1, 2, 3, 4, 5};

📝 2. Variáveis

Espaços na memória para guardar valores que podem mudar enquanto o programa roda.

👉 Regras para nomes de variáveis:

  • Começar com uma letra (ou _ )
  • Sem espaços
  • Sensível a maiúsculas e minúsculas (ex: idade ≠ Idade)

🔍 Exemplos:

int idade = 30;

double salario = 1500.75;

bool Inativo = true;

string nome = "Ana";

🔒 3. Constantes

São valores que nunca mudam depois de definidos.

Exemplo de constante:

const double PI = 3.14159;
Dica: Toda constante precisa ser inicializada na hora da declaração!

➗ 4. Operadores em C#

🧮 4.1 Operadores Aritméticos

Usados pra fazer contas básicas:

int soma = 10 + 5;

int subtracao = 10 - 3;

int produto = 4 * 2;

int divisao = 10 / 2;

int resto = 7 % 2;

🔍 4.2 Operadores Relacionais

Comparam valores e retornam verdadeiro ou falso:

bool comparacao1 = (5 == 5);  // true

bool comparacao2 = (3 != 5);  // true

bool comparacao3 = (7 > 5);   // true

🧠 4.3 Operadores Lógicos

Combinam condições booleanas:

bool resultado1 = (5 > 3) && (2 < 4);   // true

bool resultado2 = (5 > 3) || (2 > 4);   // true

bool resultado3 = !(5 > 3);             // false

✏️ 4.4 Operadores de Atribuição

Usados para atribuir ou modificar valores de variáveis:

int a = 10;

a += 5;  // Agora a = 15

a *= 2;  // Agora a = 30
