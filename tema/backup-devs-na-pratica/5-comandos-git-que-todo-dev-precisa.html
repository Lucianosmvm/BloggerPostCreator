Se você está começando a programar ou já tem alguma experiência, o Git é uma daquelas ferramentas que vão te acompanhar por toda a jornada de dev. Aqui vão os 5 comandos mais úteis e que você PRECISA conhecer:

1️⃣ git init

Cria um novo repositório Git na sua pasta atual.

git init

Quando usar? Quando quiser começar a versionar um novo projeto.

2️⃣ git add

Adiciona arquivos ao seu staging area (preparando pra um commit).

git add .

Dica: Use o ponto (.) para adicionar todos os arquivos de uma vez.

3️⃣ git commit

Salva as mudanças com uma mensagem explicativa.

git commit -m "Minha primeira atualização no projeto"

Dica: Escreva mensagens curtas e claras, o time agradece!

4️⃣ git status

Mostra quais arquivos foram modificados, adicionados ou ainda não rastreados.

git status

Quando usar? Sempre que quiser saber o que está pendente antes de fazer um commit.

5️⃣ git push

Envia seus commits locais para o repositório remoto (como GitHub, GitLab, etc).

git push origin main

Dica: Substitua main pelo nome da sua branch se for diferente.

👉 Conclusão

Claro que o Git tem muitos outros comandos, mas dominando esses 5, você já consegue trabalhar de forma básica e eficiente em qualquer projeto.
