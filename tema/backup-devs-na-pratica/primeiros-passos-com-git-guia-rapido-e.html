📌 O que é o Git?

O Git é um sistema de controle de versão super popular usado por desenvolvedores para gerenciar o código de seus projetos. Ele permite acompanhar todas as mudanças, trabalhar em equipe e evitar perdas de código.

🔧 Como instalar o Git?

👉 Acesse o site oficial: https://git-scm.com/downloads

👉 Baixe e siga o processo de instalação de acordo com seu sistema operacional (Windows, Mac ou Linux).

💻 Configurando o Git

Após instalar, abra o terminal (ou Git Bash no Windows) e configure seu nome e email:

git config --global user.name "Seu Nome"

git config --global user.email "seuemail@exemplo.com"

⚡ Principais comandos do Git

Confira os comandos básicos para começar:

👉 Criar um repositório local:

git init

👉 Verificar o status dos arquivos:

git status

👉 Adicionar arquivos para o próximo commit:

git add .

👉 Fazer um commit (salvar alterações):

git commit -m "Mensagem do commit"

👉 Conectar com um repositório remoto (ex: GitHub):

git remote add origin https://github.com/seuusuario/seurepositorio.git

👉 Enviar os commits para o GitHub:

git push -u origin main

🎯 Dica Extra!

Se estiver começando, crie uma conta no GitHub e faça seus primeiros testes criando repositórios públicos.

🚨 Conclusão

O Git pode parecer complicado no começo, mas com o tempo ele vai se tornar seu melhor amigo no desenvolvimento. Continue praticando! 😉
