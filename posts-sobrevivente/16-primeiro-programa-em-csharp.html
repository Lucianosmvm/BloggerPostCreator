Resumo rápido

  • Para programar em C# você precisa do .NET SDK (gratuito) e de um editor, como o VS Code ou o Visual Studio.
  • dotnet new console cria um projeto e dotnet run executa.
  • O código fica no arquivo Program.cs.
  • Toda instrução termina com ; e blocos de código ficam entre { }.
  • // e /* */ são comentários: o computador ignora.
  • O C# diferencia maiúsculas de minúsculas: Console funciona, console não.

Todo sobrevivente precisa dar o primeiro passo para fora do abrigo. Na programação, esse passo é fazer o computador obedecer a uma ordem sua, nem que seja escrever uma frase na tela.

Neste post você vai preparar o ambiente, criar o primeiro projeto em C#, entender cada pedaço do código e rodar o programa. É o ponto de partida de toda a série do Devs na Prática.

Instale o .NET SDK na versão mais recente (a que estiver marcada como recomendada). Para conferir se deu certo, abra o terminal (no Windows, o PowerShell ou o Prompt de Comando) e digite:

Terminal

dotnet --version

Se aparecer um número de versão, como 10.0.100, está tudo pronto.

Criando o primeiro projeto

No terminal, entre na pasta onde quer guardar seus projetos e rode:

Terminal

dotnet new console -n Sobrevivencia
cd Sobrevivencia
dotnet run
ComandoO que faz

O projeto novo já vem com um programa pronto, que mostra Hello, World!. Abra a pasta no VS Code (Arquivo → Abrir Pasta) e procure o arquivo Program.cs. É nele que você vai escrever.

Seu primeiro programa

Apague o conteúdo do Program.cs, escreva o código abaixo, salve e rode dotnet run de novo:

C#

Console.WriteLine("Você acorda num abrigo subterrâneo.");
Console.WriteLine("O rádio chia: 'Alguém aí?'");
Console.WriteLine("Sua aventura em C# começa agora.");

Saída esperada

Console.WriteLine escreve um texto na tela e pula para a próxima linha. O texto vai entre aspas duplas. Cada linha do código vira uma linha na tela, na mesma ordem: o computador lê o programa de cima para baixo.

As regras básicas da escrita

Todo idioma tem gramática, e o C# também. Estas quatro regras aparecem em qualquer programa:

1. Ponto e vírgula no fim de cada instrução. Ele é o ponto final do C#. Esquecer é o erro número um de quem começa.

2. Chaves agrupam blocos. Tudo que está entre { e } pertence ao mesmo bloco, como o corpo de um if ou de um método.

3. Maiúsculas importam. Console e console são coisas diferentes. Só a primeira existe.

4. Comentários são ignorados. Servem para explicar o código para quem lê.

C#

// Comentário de uma linha: o computador ignora tudo depois das barras
Console.WriteLine("Checando suprimentos...");

/*
   Comentário de várias linhas.
   Útil para explicar um trecho maior.
*/
Console.WriteLine("Água: ok");   // também dá para comentar no fim da linha

if (true)
{
    Console.WriteLine("Tudo entre as chaves é um bloco.");
}

Saída esperada

Checando suprimentos...
Água: ok
Tudo entre as chaves é um bloco.

E o tal do class Program?

Em tutoriais mais antigos (e em muitos códigos de empresa), o mesmo programa aparece assim:

C#

using System;

namespace Sobrevivencia
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Você acorda num abrigo subterrâneo.");
        }
    }
}

Saída esperada

Você acorda num abrigo subterrâneo.

Os dois jeitos fazem a mesma coisa. Desde o .NET 6, o C# aceita escrever o código "solto" no Program.cs (os top-level statements) e monta essa estrutura por baixo dos panos. O Main é o ponto de entrada: é por ele que o programa começa. Nos posts da série usamos o formato curto, e o formato completo quando ele for necessário.

Lendo mensagens de erro

Errar faz parte. O importante é saber ler o que o compilador diz. Se você esquecer um ponto e vírgula:

C#

Console.WriteLine("Sem ponto e vírgula")

o dotnet run mostra algo como Program.cs(1,41): error CS1002: ; expected. Leia assim: arquivo Program.cs, linha 1, coluna 41, erro: "esperava um ;". O número da linha leva você direto ao problema.

Mensagem (em inglês)O que costuma ser
; expectedfaltou ponto e vírgula
} expecteduma chave foi aberta e não foi fechada
The name 'console' does not existmaiúscula/minúscula errada, ou nome digitado errado
Newline in constantfaltou fechar as aspas do texto
