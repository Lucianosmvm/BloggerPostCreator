`Console.WriteLine` mostra um texto e pula para a próxima linha. `Console.Write` mostra o texto e continua na mesma linha. `Console.ReadLine` espera o jogador digitar e devolve o que ele escreveu como `string`. Para usar o que foi digitado como número, converta com `int.Parse` ou, melhor, `int.TryParse`. `$"..."` coloca variáveis no meio do texto.

Um jogo que não fala com o jogador é só uma tela preta. Antes de ter gráficos, todo programa em C# começa conversando pelo console: mostra mensagens e lê o que a pessoa digita.

Neste post você vai montar a tela inicial de um jogo de sobrevivência: dar as boas-vindas, perguntar o nome do personagem e quantas ervas ele leva na mochila.

Console.WriteLine: mostrando mensagens

O Console.WriteLine escreve o texto na tela e pula para a linha de baixo. Cada chamada vira uma linha:

Console.WriteLine("=== CIDADE ABANDONADA ==="); Console.WriteLine("Você acorda num hospital vazio."); Console.WriteLine("A porta está trancada."); === CIDADE ABANDONADA === Você acorda num hospital vazio. A porta está trancada.

Você pode mostrar números e variáveis também. Para misturar texto e variável, use a interpolação com $ e chaves:

string nome = "Claire"; int vida = 100; int balas = 9; Console.WriteLine($"Personagem: {nome}"); Console.WriteLine($"Vida: {vida} | Balas: {balas}"); Console.WriteLine($"Balas em dobro: {balas * 2}"); Personagem: Claire Vida: 100 | Balas: 9 Balas em dobro: 18

Dentro das chaves pode ir uma conta inteira, como {balas * 2}. O C# calcula e coloca o resultado no texto.

Console.Write: na mesma linha

O Console.Write faz o mesmo, mas não pula linha. É útil para montar uma linha aos poucos, como uma barra de vida:

Console.Write("Vida: "); Console.Write("["); Console.Write("#######"); Console.Write("..."); Console.WriteLine("]"); Console.WriteLine("Cuidado, você está ferido."); Vida: [#######...] Cuidado, você está ferido. Comando | O que faz | Quando usar `Console.WriteLine("x")` | escreve e pula linha | mensagens normais `Console.Write("x")` | escreve sem pular linha | perguntas e barras `Console.WriteLine()` | só pula uma linha | separar blocos de texto `Console.ReadLine()` | lê uma linha digitada | respostas do jogador

Console.ReadLine: ouvindo o jogador

O Console.ReadLine para o programa e espera o jogador digitar algo e apertar Enter. O que ele escreveu volta como string, que você guarda numa variável:

Console.Write("Qual é o nome do seu personagem? "); string nome = Console.ReadLine(); Console.WriteLine($"Boa sorte, {nome}. Não faça barulho."); Qual é o nome do seu personagem? Jill Boa sorte, Jill. Não faça barulho.

Repare no truque: a pergunta usa Console.Write, então o cursor fica na mesma linha e o jogador digita logo depois do ponto de interrogação.

Em projetos novos o Visual Studio pode sublinhar o `Console.ReadLine()` com um aviso de que ele pode devolver `null`. Para quem está começando, o código funciona normalmente. Se quiser tirar o aviso, use `string nome = Console.ReadLine() ?? "";`.

Lendo números: int.Parse

Tudo que vem do ReadLine é texto. Se você perguntar quantas ervas o jogador tem e tentar fazer conta direto, não vai funcionar: "3" + 1 vira "31", porque o C# junta textos. Para virar número, converta com int.Parse:

Console.Write("Quantas ervas você tem? "); string resposta = Console.ReadLine(); int ervas = int.Parse(resposta); int cura = ervas * 25; Console.WriteLine($"Com {ervas} ervas você recupera {cura} de vida."); Quantas ervas você tem? 3 Com 3 ervas você recupera 75 de vida.

Para números com casas decimais existe o double.Parse, que funciona do mesmo jeito.

Quando o jogador digita errado: int.TryParse

O int.Parse tem um problema: se o jogador digitar "três" ou deixar em branco, o programa quebra com um erro (FormatException). Em jogo isso é game over sem motivo.

O int.TryParse tenta converter e responde se deu certo, sem quebrar nada:

Console.Write("Quantas balas você quer carregar? "); string resposta = Console.ReadLine(); if (int.TryParse(resposta, out int balas)) { Console.WriteLine($"Carregando {balas} balas..."); } else { Console.WriteLine("Isso não é um número. Digite só algarismos, como 6."); } Quantas balas você quer carregar? três Isso não é um número. Digite só algarismos, como 6.

O TryParse devolve true ou false, e o número convertido sai pela variável depois do out. Por isso ele cabe direto dentro de um if.

Juntando tudo: a tela inicial do jogo

Console.WriteLine("=== CIDADE ABANDONADA ==="); Console.WriteLine(); Console.Write("Nome do personagem: "); string nome = Console.ReadLine(); Console.Write("Quantas ervas na mochila? "); int.TryParse(Console.ReadLine(), out int ervas); int vida = 50 + ervas * 25; Console.WriteLine(); Console.WriteLine($"{nome} começa com {vida} de vida."); Console.WriteLine("Pressione Enter para entrar na cidade."); === CIDADE ABANDONADA === Nome do personagem: Leon Quantas ervas na mochila? 2 Leon começa com 100 de vida. Pressione Enter para entrar na cidade.

Se o jogador digitar algo que não é número na segunda pergunta, o TryParse deixa ervas valendo 0 e o jogo segue com 50 de vida, sem quebrar.

Erros comuns

1. Fazer conta com o texto do ReadLine. Console.ReadLine() + 1 junta textos. Converta antes.

2. Esquecer o $. Sem ele, "Vida: {vida}" aparece na tela com as chaves e tudo.

3. Usar int.Parse com entrada do jogador. Funciona até alguém digitar errado. Prefira int.TryParse.

4. Programa que fecha sozinho. Se a janela some antes de você ler, coloque um Console.ReadLine(); no final para ela esperar um Enter.

O que aparece na tela? `Console.Write("A"); Console.Write("B"); Console.WriteLine("C"); Console.WriteLine("D");` `ABC` na primeira linha e `D` na segunda. Só o `WriteLine` pula linha. O jogador digitou `5`. Quanto vale `Console.ReadLine() + 5`? O texto `"55"`. O `ReadLine` devolve string e o `+` junta textos. Converta com `int.Parse` ou `int.TryParse` antes. Escreva o código que pergunta a vida atual do personagem e mostra quanto falta para 100, sem quebrar se a pessoa digitar letras. `Console.Write("Vida atual: ");` e depois `if (int.TryParse(Console.ReadLine(), out int vida)) Console.WriteLine($"Faltam {100 - vida}"); else Console.WriteLine("Digite um número.");`

Conclusão

Com WriteLine, Write e ReadLine o seu programa já conversa com o jogador. E com o TryParse ele não cai quando alguém digita bobagem, o que já coloca o seu código à frente de muito iniciante.
