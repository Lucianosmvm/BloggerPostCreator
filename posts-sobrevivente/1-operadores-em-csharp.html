Resumo rápido

  • Operadores aritméticos fazem contas: +, -, *, / e %.
  • Operadores de comparação respondem sim ou não: ==, !=, >, <, >= e <=.
  • Operadores lógicos juntam condições: && (e), || (ou) e ! (não).
  • Divisão entre dois int descarta a parte decimal: 7 / 2 dá 3.
  • Os atalhos +=, -= e ++ deixam o código mais curto.

Num jogo de sobrevivência, tudo é conta e decisão: quanto de vida sobrou depois do ataque, se ainda tem munição, se dá para abrir a porta. No código é igual. Quem faz esse trabalho são os operadores.

Neste post você vai ver os três grupos de operadores que mais aparecem no C#, sempre com um exemplo de jogo e o resultado que aparece na tela.

Operadores aritméticos: as contas do jogo

São os operadores de matemática. Eles pegam dois valores e devolvem um novo valor.

OperadorO que fazExemploResultado
+Soma80 + 20100
-Subtração100 - 3565
*Multiplicação3 * 1545
/Divisão7 / 23 (entre int)
%Resto da divisão17 % 52

Veja um ataque tirando vida do personagem e a munição sendo dividida em pentes:

C#

int vida = 100;
int dano = 35;
vida = vida - dano;
Console.WriteLine($"Vida depois do ataque: {vida}");

int balas = 17;
int tamanhoDoPente = 5;
Console.WriteLine($"Pentes cheios: {balas / tamanhoDoPente}");
Console.WriteLine($"Balas soltas: {balas % tamanhoDoPente}");

Saída esperada

Vida depois do ataque: 65
Pentes cheios: 3
Balas soltas: 2

O % parece estranho no começo, mas é muito útil: ele diz o que sobra de uma divisão. 17 balas em pentes de 5 dão 3 pentes cheios (15 balas) e sobram 2.

⚠️ Cuidado com a divisão entre dois int: 7 / 2 dá 3, porque o C# joga fora a parte decimal. Para ter 3.5, pelo menos um dos lados precisa ser double: 7.0 / 2.

Atalhos de atribuição: +=, -= e ++

Escrever vida = vida - dano o tempo todo cansa. O C# tem atalhos que fazem a mesma coisa:

C#

int vida = 100;
vida -= 35;   // mesmo que vida = vida - 35
vida += 20;   // erva verde: vida = vida + 20

int inimigosDerrotados = 0;
inimigosDerrotados++;   // soma 1

Console.WriteLine($"Vida: {vida} | Inimigos: {inimigosDerrotados}");

Saída esperada

Vida: 85 | Inimigos: 1

Operadores de comparação: a pergunta de sim ou não

Esses operadores comparam dois valores e sempre devolvem um bool: true (verdadeiro) ou false (falso). São eles que vão alimentar o if no próximo post da série.

OperadorPerguntaExemplo (vida = 30)Resultado
==É igual?vida == 30true
!=É diferente?vida != 0true
>É maior?vida > 50false
<É menor?vida < 50true
>=É maior ou igual?vida >= 30true
<=É menor ou igual?vida <= 29false

⚠️ Erro clássico: = guarda um valor, == compara. vida = 0 mata o personagem; vida == 0 só pergunta se ele morreu.

Operadores lógicos: juntando condições

Muitas decisões dependem de mais de uma coisa. Para abrir a porta do castelo você precisa ter a chave e estar vivo. Para isso existem os operadores lógicos:

  • && (e): só é true se as duas condições forem verdadeiras.
  • || (ou): é true se pelo menos uma for verdadeira.
  • ! (não): inverte o valor: !true vira false.

C#

bool temChave = true;
int vida = 30;
int municao = 0;

bool podeAbrirPorta = temChave && vida > 0;
bool precisaDeAjuda = vida < 50 || municao == 0;
bool estaDesarmado = !(municao > 0);

Console.WriteLine($"Pode abrir a porta? {podeAbrirPorta}");
Console.WriteLine($"Precisa de ajuda? {precisaDeAjuda}");
Console.WriteLine($"Está desarmado? {estaDesarmado}");

Saída esperada

Pode abrir a porta? True
Precisa de ajuda? True
Está desarmado? True

Repare que o C# escreve True e False com letra maiúscula quando mostra um bool na tela, mas no código você escreve true e false em minúsculas.

Ordem das operações

Assim como na matemática, o C# resolve primeiro *, / e %, depois + e -, depois as comparações e só no fim && e ||. Na dúvida, use parênteses: eles deixam a intenção clara para quem lê.

C#

int pontos = 10 + 5 * 2;     // 20, não 30
int pontos2 = (10 + 5) * 2;  // 30
Console.WriteLine($"{pontos} e {pontos2}");

Saída esperada

20 e 30
