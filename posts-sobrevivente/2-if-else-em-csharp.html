Resumo rápido

  • O if executa um bloco só quando a condição é verdadeira.
  • O else é o caminho quando a condição é falsa.
  • O else if testa outras condições em sequência; só o primeiro caminho verdadeiro roda.
  • A condição sempre resulta em bool, geralmente vinda de operadores de comparação.

Todo jogo de sobrevivência é feito de decisões: a vida está baixa? Cure. A porta está trancada? Procure a chave. No código, quem toma essas decisões é o if.

Se você ainda não viu os operadores de comparação (>, ==, &&...), dê uma olhada no post anterior da série: Operadores em C#. Eles são o combustível do if.

O if: só entra se for verdade

A estrutura é sempre a mesma: a palavra if, uma condição entre parênteses e um bloco entre chaves. O bloco só roda se a condição for true.

C#

int vida = 25;

if (vida < 30)
{
    Console.WriteLine("Vida baixa! Use uma erva verde.");
}

Console.WriteLine("Fim do turno.");

Saída esperada

Vida baixa! Use uma erva verde.
Fim do turno.

Se vida fosse 80, o aviso não apareceria e o programa iria direto para "Fim do turno.".

O else: o outro caminho

Quando você quer fazer uma coisa se a condição for verdadeira e outra se for falsa, use o else. Exatamente um dos dois blocos vai rodar.

C#

bool temChave = false;

if (temChave)
{
    Console.WriteLine("A porta do castelo abriu.");
}
else
{
    Console.WriteLine("Trancada. Procure a chave.");
}

Saída esperada

Trancada. Procure a chave.

Repare que if (temChave) funciona sem == true: a variável já é um bool.

O else if: várias faixas de decisão

Às vezes há mais de dois caminhos. A barra de vida do jogo, por exemplo, pode ser verde, amarela ou vermelha. O else if testa as condições de cima para baixo e para no primeiro que der verdadeiro.

C#

int vida = 45;

if (vida >= 70)
{
    Console.WriteLine("Barra verde: tudo certo.");
}
else if (vida >= 30)
{
    Console.WriteLine("Barra amarela: cuidado.");
}
else
{
    Console.WriteLine("Barra vermelha: cure agora!");
}

Saída esperada

Barra amarela: cuidado.

Com 45 de vida, o primeiro teste (>= 70) falha, o segundo (>= 30) passa e o resto é ignorado. Não precisa escrever vida >= 30 && vida < 70: se chegou no segundo teste, já se sabe que a vida é menor que 70.

70vida >= 70Barra verde

Condições compostas com && e ||

Dá para juntar várias condições num único if:

C#

int municao = 0;
bool temFaca = true;

if (municao > 0)
{
    Console.WriteLine("Atire!");
}
else if (temFaca)
{
    Console.WriteLine("Sem balas. Use a faca.");
}
else
{
    Console.WriteLine("Sem nada. Corra!");
}

Saída esperada

Sem balas. Use a faca.

Erros comuns

  • Usar = no lugar de ==: if (vida = 0) nem compila em C# para int. Comparação é ==.
  • Ponto e vírgula depois do if: if (vida < 30); encerra o if ali mesmo, e o bloco de baixo roda sempre.
  • Ordem errada no else if: se o teste mais amplo (vida >= 30) vier antes do mais específico (vida >= 70), a barra verde nunca aparece.
  • Esquecer as chaves: sem { }, só a primeira linha depois do if faz parte dele. Use chaves sempre.

Conclusão

Com if, else e else if o seu programa deixa de seguir uma linha reta e passa a reagir à situação. Quando a decisão depende de um único valor com muitas opções, como um menu, existe uma forma mais organizada de escrever: o switch.
