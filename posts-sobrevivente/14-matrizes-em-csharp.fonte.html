Matriz é um array com duas dimensões: linhas e colunas, como um tabuleiro. Cria com `int[,] mapa = new int[3, 4];` (3 linhas, 4 colunas). Acessa com dois índices: `mapa[linha, coluna]`, ambos começando em 0. `GetLength(0)` dá o número de linhas e `GetLength(1)` o de colunas. Para percorrer, use um `for` dentro de outro.

Um array comum é uma fila de compartimentos, como a maleta do post Arrays em C#. Mas o mapa de um jogo não é uma fila: é uma grade, com linhas e colunas. Para isso o C# tem as matrizes, ou arrays bidimensionais.

Neste post você vai montar o mapa de um prédio abandonado, posicionar o jogador e os zumbis e desenhar tudo no console.

Criando a matriz

A vírgula dentro dos colchetes indica as duas dimensões. Você pode criar vazia, informando o tamanho, ou já com os valores:

// 0 = chão, 1 = parede, 2 = zumbi int[,] mapa = { { 1, 1, 1, 1, 1 }, { 1, 0, 0, 2, 1 }, { 1, 0, 1, 0, 1 }, { 1, 1, 1, 1, 1 } }; Console.WriteLine($"Linhas: {mapa.GetLength(0)}"); Console.WriteLine($"Colunas: {mapa.GetLength(1)}"); Console.WriteLine($"Total de casas: {mapa.Length}"); Console.WriteLine($"O que tem na linha 1, coluna 3? {mapa[1, 3]}"); Linhas: 4 Colunas: 5 Total de casas: 20 O que tem na linha 1, coluna 3? 2 Comando | O que devolve | No mapa `mapa[linha, coluna]` | o valor de uma casa | `mapa[1, 3]` é 2 (zumbi) `mapa.GetLength(0)` | quantidade de linhas | 4 `mapa.GetLength(1)` | quantidade de colunas | 5 `mapa.Length` | total de casas | 20 `new int[4, 5]` | matriz vazia (tudo 0) | 4 linhas, 5 colunas

A ordem é sempre linha primeiro, coluna depois. Pense em "andar para baixo, depois para o lado". E, como no array comum, os índices começam em 0.

Lendo e mudando uma casa

int[,] mapa = new int[3, 3]; // tudo começa em 0 (chão) mapa[0, 2] = 2; // zumbi no canto de cima, à direita mapa[1, 1] = 1; // parede no meio if (mapa[0, 2] == 2) Console.WriteLine("Cuidado: zumbi na sala do canto!"); mapa[0, 2] = 0; // zumbi derrotado Console.WriteLine($"Agora a casa [0, 2] vale {mapa[0, 2]}."); Cuidado: zumbi na sala do canto! Agora a casa [0, 2] vale 0.

Percorrendo com for aninhado

Para passar por todas as casas, use um for para as linhas e, dentro dele, outro para as colunas. Assim dá para desenhar o mapa inteiro:

int[,] mapa = { { 1, 1, 1, 1, 1 }, { 1, 0, 0, 2, 1 }, { 1, 0, 1, 0, 1 }, { 1, 1, 1, 1, 1 } }; int jogadorLinha = 2, jogadorColuna = 1; for (int l = 0; l < mapa.GetLength(0); l++) { for (int c = 0; c < mapa.GetLength(1); c++) { if (l == jogadorLinha && c == jogadorColuna) Console.Write("@"); else if (mapa[l, c] == 1) Console.Write("#"); else if (mapa[l, c] == 2) Console.Write("Z"); else Console.Write("."); } Console.WriteLine(); // fim da linha do mapa } ##### #..Z# #@#.# #####

O for de fora roda uma vez por linha; o de dentro roda todas as colunas daquela linha. O Console.Write desenha na mesma linha e o Console.WriteLine() no fim pula para a próxima.

Contando coisas no mapa

O mesmo par de laços serve para procurar e contar. Com foreach fica ainda mais curto, porque ele passa por todas as casas em ordem:

int[,] mapa = { { 2, 0, 0, 2 }, { 0, 1, 1, 0 }, { 2, 0, 0, 2 } }; int zumbis = 0; foreach (int casa in mapa) { if (casa == 2) zumbis++; } Console.WriteLine($"Zumbis no andar: {zumbis}"); for (int l = 0; l < mapa.GetLength(0); l++) for (int c = 0; c < mapa.GetLength(1); c++) if (mapa[l, c] == 2) Console.WriteLine($"Zumbi em [{l}, {c}]"); Zumbis no andar: 4 Zumbi em [0, 0] Zumbi em [0, 3] Zumbi em [2, 0] Zumbi em [2, 3]

Use foreach quando só importa o valor, e o for duplo quando você precisa saber a posição.

Movendo o jogador sem atravessar parede

int[,] mapa = { { 1, 1, 1, 1 }, { 1, 0, 0, 1 }, { 1, 1, 0, 1 }, { 1, 1, 1, 1 } }; int linha = 1, coluna = 1; Mover(0, 1); // direita Mover(1, 0); // baixo Mover(0, -1); // esquerda: parede! void Mover(int dl, int dc) { int novaLinha = linha + dl, novaColuna = coluna + dc; if (mapa[novaLinha, novaColuna] == 1) { Console.WriteLine($"Parede em [{novaLinha}, {novaColuna}]. Você fica parado."); return; } linha = novaLinha; coluna = novaColuna; Console.WriteLine($"Você foi para [{linha}, {coluna}]."); } Você foi para [1, 2]. Você foi para [2, 2]. Parede em [2, 1]. Você fica parado.

Antes de mover, o código olha a casa de destino. Esse "olhar antes de pisar" é a base da colisão em jogos de grade.

Matriz ou array de arrays?

O C# tem outro formato parecido, o array de arrays (jagged array), escrito int[][]. Nele, cada linha é um array separado e pode ter tamanho diferente:

Comparação | Matriz `int[,]` | Array de arrays `int[][]` Formato | retângulo, todas as linhas iguais | cada linha com seu tamanho Acesso | `mapa[1, 3]` | `andares[1][3]` Tamanho | `GetLength(0)` e `GetLength(1)` | `andares.Length` e `andares[i].Length` Bom para | mapas, tabuleiros, grades | listas de tamanhos diferentes, como inimigos por andar

Erros comuns

1. Trocar linha e coluna. mapa[coluna, linha] lê a casa errada ou sai da matriz. Padronize: sempre [linha, coluna].

2. Usar Length no laço. mapa.Length é o total de casas (20), não o número de linhas. Use GetLength(0) e GetLength(1).

3. Sair da borda. mapa[4, 0] num mapa de 4 linhas dá IndexOutOfRangeException. Por isso o mapa do exemplo tem paredes em volta: o jogador nunca chega à borda.

Crie uma matriz `int` com 2 linhas e 3 colunas, toda zerada, e coloque o valor 5 no canto de baixo, à direita. `int[,] m = new int[2, 3]; m[1, 2] = 5;` Num mapa `new int[6, 8]`, quanto valem `GetLength(0)`, `GetLength(1)` e `Length`? 6, 8 e 48. Escreva o laço que conta quantas paredes (valor 1) existem no mapa. `int paredes = 0; foreach (int casa in mapa) if (casa == 1) paredes++;`

Conclusão

Com uma matriz e dois laços você já tem a estrutura de um jogo de grade: mapa, paredes, inimigos e um jogador que anda sem atravessar nada. O mesmo formato serve para tabuleiros, planilhas e imagens.

Quando o número de itens muda o tempo todo, arrays de tamanho fixo começam a atrapalhar. Aí entram as coleções.
